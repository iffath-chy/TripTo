# TripTo✈️
TripTo ✈️ is an AI-powered travel planning chatbot developed using Python, LangGraph, Google Gemini API, and Tkinter. It helps users plan trips by providing destination information, travel recommendations, personalized itineraries, budgeting suggestions, and travel tips through a simple chat interface.

The chatbot combines the reasoning capabilities of Google's Gemini AI with LangGraph's workflow management to deliver intelligent and interactive travel assistance. Users can ask about destinations, attractions, best times to visit, transportation options, and travel plans. TripTo analyzes the user's request and generates relevant travel guidance in real time.

The application features a modern graphical user interface with both text-based interaction and optional voice output. Upon launch, TripTo greets the user with a welcome message and is ready to assist with travel planning. The system is designed to make trip planning easier, faster, and more personalized by acting as a virtual travel assistant.

Key Features:
• AI-powered travel recommendations
• Destination and attraction suggestions
• Personalized itinerary generation
• Interactive chat interface
• Optional voice responses
• LangGraph-based workflow management
• Gemini API integration for intelligent responses
• User-friendly desktop application built with Tkinter

TripTo aims to simplify travel planning by providing travelers with quick, accurate, and personalized guidance for their journeys.
